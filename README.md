# STS2 皮肤切换器

一个独立的《杀戮尖塔 2》皮肤管理 Mod。它不会修改其他 Mod，也不依赖旧版“皮肤管理器”。

## 功能

- 自动识别已加载、且 `affects_gameplay=false` 的纯外观 PCK，以及通过 DLL 接管原场景的外观 Mod。
- 按角色、远古者以及怪物分别归类皮肤。
- 每一组都可切回游戏原版或当前玩法 Mod 提供的基础外观。
- 在选角界面切换当前角色的皮肤。
- 在卡牌总览中切换当前角色或颜色的卡牌皮肤；角色、无色、远古以及“其他”（事件、衍生、状态、诅咒、任务）分类分别保存，并可只显示确实拥有皮肤的卡牌。
- 放大任意卡牌后，可在卡牌顶部为这一张卡单独选择卡图 Mod、切回原版，或继续跟随所属分类；提供者针对 `NCard` 的卡框、遮罩、材质和布局方法，以及仅在卡牌 UI 中生效的卡面模式方法，会被隔离登记。管理器只沿这些方法的实际调用链加载小型配置与外框依赖；卡图替换和纹理过滤仍由管理器自身完成，不会重复运行提供者的整套卡图加载器。
- 卡图包中与玩法基线完全相同的重复资源会被忽略；完整类型名、`generated/assets/card_art` 及提供者私有目录下的散装卡图均会按实际 ModelDb 卡名归类。同一 Mod 内真正不同的子目录变体会拆成独立选项；约定俗成的 `beta` 目录作为同一卡牌备用图处理，不单独伪装成皮肤。未覆盖的卡牌自动从隔离基线加载。
- 在怪物图鉴切换当前怪物的皮肤。
- 在怪物图鉴右侧的小入口打开远古图鉴，并切换当前远古者的皮肤。
- 选择后立即生成并挂载资源覆盖包，无需重启游戏。
- 被识别为皮肤提供者后，其 DLL 初始化器和全局补丁不会执行；只登记可隔离重放的卡牌呈现方法。PCK 只按当前分组选择读取场景、骨骼、贴图及场景自身依赖，避免未选中皮肤强制占用或跨分组串皮。
- 选择保存在游戏用户目录的 `sts2_skin_switcher.json` 中，下次启动自动应用。
- 不改写任何已安装 Mod 的 PCK。

## 使用

将发布目录放到游戏的 `mods/STS2SkinChanger` 下并正常启用。角色皮肤选项会出现在选角界面；卡牌皮肤选项和“仅显示有皮肤的卡牌”筛选会出现在卡牌总览“多人模式卡牌”选项上方，并跟随当前选中的角色或颜色卡池；放大卡牌后，顶部会出现只影响当前卡牌的选择器；怪物皮肤选项会出现在怪物图鉴；远古图鉴与角色数据位于图鉴底部的同一级入口。没有对应皮肤时不会显示切换控件。

仅替换皮肤资源、并正确声明 `affects_gameplay=false` 的 Mod 才会作为候选项出现。DLL 外观 Mod 会根据它随附的模板资源、启用配置或远古图片目录加入相应选项，但不会执行初始化器或安装全局补丁；仅有明确作用于 `NCard` 的后置呈现方法会在对应卡图被选中时调用。PCK 卡图会识别标准目录和 Mod 自定义的卡图目录，并按卡牌总览的实际筛选规则归类。一个 Mod 若同时影响角色色与远古/其他卡牌，会出现在对应的多个分类中。混合玩法内容的 Mod 会作为当前基础资源的一部分，不会被误判为皮肤。

## 构建

项目引用本机游戏目录中的 `GodotSharp.dll`、`0Harmony.dll` 和 `sts2.dll`：

```bash
dotnet build STS2SkinChanger/STS2SkinChanger.csproj -c Release
```

产物位于 `STS2SkinChanger/bin/Release/STS2SkinChanger.dll`。

## 开发检查工具

- `tools/PckInspect`：检查 PCK 目录或复制少量文件验证写入器。
- `tools/CatalogInspect`：用实际游戏与 Mod PCK 构建皮肤目录，输出识别结果。
