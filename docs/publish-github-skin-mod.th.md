# เผยแพร่สกินของคุณบน GitHub (คู่มือสำหรับผู้สร้าง)

[简体中文](投稿GitHub皮肤Mod说明.md) · [English](publish-github-skin-mod.md)

ผู้เล่นที่ติดตั้ง «Skin Changer» ไว้ จะเห็นรีโพของคุณในเกมที่ **☼เวิร์กชอปสกิน → แหล่งที่มา: GitHub** และติดตั้งได้ในคลิกเดียว
สิ่งที่ต้องทำมีแค่สามอย่าง: เพิ่มหนึ่งทอปิก เผยแพร่หนึ่ง zip และวางหนึ่งรหัส

(ถ้าจะสแกนแพ็กของตัวเอง ต้องติดตั้ง Skin Changer ก่อน — ค้นหาได้ในเวิร์กชอปของ Steam)

## 1. เพิ่มทอปิก

ที่หน้ารีโพของคุณ: ไอคอนรูปเฟืองข้าง About → Topics:

```
sts2-sc-mod
```

ถ้าไม่ใส่ทอปิกหรือสะกดผิด เกมจะหารีโพของคุณไม่เจอเลย รีโพที่ fork มาก็จะไม่แสดงเช่นกัน

## 2. เผยแพร่ Release พร้อม zip

- ใน zip คือแพ็กสกินที่เกมโหลดได้ (`<id>.json` + `.pck` / `.dll` แพ็กที่มีแต่ภาพการ์ดก็ใช้ได้)
- วางไฟล์ไว้ที่**ราก**ของ zip หรือใส่ไว้ในโฟลเดอร์ (ซ้อนกี่ชั้นก็ได้ จะเลือกโฟลเดอร์ที่ชื่อเดียวกับรีโพก่อน ก็ต่อเมื่อใน zip มีหลาย Mod เท่านั้น)
- อ่านเฉพาะ `.zip` เท่านั้น: `.rar` `.7z` และ `.tar.gz` ถือว่าไม่มีไฟล์แนบ รีโพจะค้างอยู่ที่ «ไม่รู้จัก»
- แนบเข้ากับ Release **ล่าสุด** และ**อย่า**ติ๊ก pre-release (ติ๊กแล้วแผงอ่านไม่ได้) ไฟล์แนบหนึ่งชิ้นต้องไม่เกิน 128 MB
- ส่ง zip เดียวง่ายที่สุด ถ้าส่งหลายไฟล์ แผงจะเลือกอันที่ชื่อเดียวกับรีโพก่อน ไม่มีก็เลือกอันที่ใหญ่สุด
- zip จะ**เพิ่มภายหลังหลังเผยแพร่ Release แล้วก็ได้**: ตอนกด «สแกน» ระบบจะอ่าน Release ปัจจุบันใหม่ ไม่ต้องแก้ tag หรือส่งใหม่

## 3. บันทึกรหัสเป็น sc.info

1. ในเกม → ☼เวิร์กชอปสกิน → สลับแหล่งที่มาเป็น **GitHub** → ตัวกรองเลือก **ไม่รู้จัก** → หารีโพของคุณ
2. กด **สแกน** (เฉพาะตอนนี้เท่านั้นที่จะดาวน์โหลด zip ของคุณ และถูกลบทันทีหลังสแกนเสร็จ) หน้าต่างจะแสดง**รหัส**หนึ่งหรือหลายชุด แต่ละชุดมีปุ่มคัดลอก
3. สร้างไฟล์ชื่อ `sc.info` ที่**รากของรีโพ** วางรหัสลงไปแล้วคอมมิต
4. กลับไปในเกมแล้วกดรีเฟรช: รีโพของคุณจะเปลี่ยนจาก «ไม่รู้จัก» เป็นสกินที่ติดตั้งได้ (ชื่อการ์ดใช้**ชื่อรีโพ**)

### วางหลายรหัสอย่างไร

**หนึ่งรหัสต่อหนึ่งบรรทัด วางจากบนลงล่างตามลำดับ** เท่านี้เอง:

```
SCM3 6714 3f2a… (ตัวอย่าง รหัสจริงเป็นบรรทัดเดียวยาว ๆ) 1/2 eJw…Cd34
SCM3 6714 3f2a… (ตัวอย่าง รหัสจริงเป็นบรรทัดเดียวยาว ๆ) 2/2 eJw…Cd34
```

กฎเหล็กมีแค่สี่ข้อ:

- **ห้ามตัดรหัสข้ามบรรทัด** รหัสหนึ่งชุดต้องอยู่ครบในบรรทัดเดียว โปรแกรมแก้ไขข้อความพับบรรทัดยาวให้ดูไม่เป็นไร แต่กด Enter กลางรหัสถือว่าพัง
- **ห้ามขาดแม้แต่ชุดเดียว** มีกี่ชุดตามหน้าต่างแสดง ต้องวางครบทุกชุด ถ้าขาดชุดเดียวทั้งแพ็กจะอ่านไม่ได้ รีโพจะค้างที่ «ไม่รู้จัก»
- **ห้ามแก้ไขด้วยมือ** รหัสมีเช็คซัมในตัว แก้แม้แต่ตัวอักษรเดียว (รวมถึงเติมช่องว่าง) ถือว่าใช้ไม่ได้
- **ห้ามครอบด้วยเครื่องหมายคำพูด** แบบ `"SCM3 …"` จะถูกมองเป็นข้อความอ้างอิงและถูกข้าม

นอกนั้นยืดหยุ่นหมด: ลำดับไม่สำคัญ บรรทัดว่างไม่สำคัณ แทรกหัวข้อหรือคำอธิบายได้ ครอบด้วยบล็อกโค้ด Markdown ได้ หรือวางสองรหัสคั่นด้วยช่องว่างในบรรทัดเดียวก็รับรู้ ทั้งไฟล์อย่าเกิน 64 KB

## ผู้เล่นเห็นอะไร

ป้ายชนิด/เป้าหมายและคำแนะนำ «ต้องเริ่มเกมใหม่» มาจากรหัส ระบบตรวจจับตอนสแกนให้อัตโนมัติ คุณไม่ต้องกรอกเอง แพ็กที่เพิ่งติดตั้งจะไม่ถูกเกมที่กำลังเล่นอยู่โหลดทันที แผงจึงแจ้งเตือนให้เริ่มเกมใหม่เหมือน Steam และมีผลหลังเริ่มเกมใหม่

## ข้อผิดพลาดที่พบบ่อย

- **เปลี่ยนชื่อรีโพหรือเปลี่ยนบัญชี**: คู่ `เจ้าของ/รีโพ` เปลี่ยนไป รหัสเก่าใช้ไม่ได้ทันที — สแกนใหม่แล้วคอมมิตรหัสใหม่
- **เผยแพร่แค่ dll / pck กระจัดกระจายโดยไม่มี zip**: รีโพจะขึ้นในรายการ แต่เป็น «ไม่รู้จัก» ตลอดไป ไม่มีปุ่มติดตั้ง
- **วางรหัสของรีโพอื่น**: ก็เป็น «ไม่รู้จัก» เช่นกัน — รหัสผูกกับรีโพของมันเอง
- **อัปเดตสกิน**: แค่เผยแพร่ Release ใหม่ก็พอ ต้องสแกนใหม่และอัปเดต `sc.info` เฉพาะเมื่อ**เป้าหมายที่ถูกแทนที่เปลี่ยนไป** หรือ**เพิ่มสคริปต์ / DLL (ความต้องเริ่มเกมใหม่เปลี่ยน)** เท่านั้น การเปลี่ยนแค่ภาพไม่ต้อง
