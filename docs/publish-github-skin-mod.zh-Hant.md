# 把你的皮膚發到 GitHub（作者說明）

[简体中文](投稿GitHub皮肤Mod说明.md) · [English](publish-github-skin-mod.md)

玩家裝了「外觀切換器」後，會在遊戲裡的 **☼皮膚創意工坊 → 來源：GitHub** 看到你的倉庫，點一下就能安裝。
你要做的只有三件事：加一個標籤、發一個 zip、貼一段碼。

（自己先用面板掃描，需要先裝好外觀切換器，Steam 創意工坊搜 Skin Changer。）

## 一、給倉庫加標籤

倉庫頁面右側 About 旁的齒輪 → Topics 填：

```
sts2-sc-mod
```

標籤沒加或拼錯，遊戲裡就找不到你的倉庫；fork 出來的倉庫也不會出現。

## 二、發一個 Release，附件傳 zip

- zip 裡就是遊戲能載入的那份外觀包（`<id>.json` + `.pck` / `.dll`，純卡片圖素材包也行）。
- 包內檔案放在 zip 的**根目錄**，或者放在資料夾裡（套幾層都行；只有包裡含多個 Mod 時，才優先挑資料夾名與倉庫同名的那一個）。
- 只認 `.zip`：`.rar`、`.7z`、`.tar.gz` 一律當作沒有附件，倉庫會停在「未識別」。
- 掛在**最新**的那個 Release 上，**不要勾 pre-release**（勾了面板讀不到）；單一附件不超過 128 MB。
- 只傳一個 zip 最省事。傳了多個時，面板優先挑名字與倉庫同名的那个，否則挑最大的。
- 壓縮包可以**先發 Release、後補附件**：點「掃描」時會重新讀取即時 Release，不用改 tag 或重新提交。

## 三、把資訊碼存成 sc.info

1. 進遊戲 → ☼皮膚創意工坊 → 來源切到 **GitHub** → 篩選選 **未識別** → 找到你的倉庫。
2. 點 **掃描**（這時才會下載你的 zip，掃完即刪）。彈窗裡會出現 1 段或多段**資訊碼**，每段右邊都有「複製」。
3. 在倉庫**根目錄**新建檔案 `sc.info`，把碼貼進去，提交。
4. 回遊戲點重新整理：你的倉庫就從「未識別」變成可以安裝的外觀（卡片名字用的是**倉庫名**）。

### 多段碼怎麼貼

**一段碼一行，從上到下依次貼**，就這樣，不用想別的：

```
SCM3 6714 3f2a…（示意，實際是一整行很長的字元）1/2 eJw…Cd34
SCM3 6714 3f2a…（示意，實際是一整行很長的字元）2/2 eJw…Cd34
```

只有四條硬規則：

- **一段碼不能斷行**：一段碼必須完整待在同一行裡。編輯器把長行折起來顯示沒關係，手動敲 Enter 就廢了。
- **一段都不能少**：彈窗裡幾段就貼幾段。少一段整個包讀不出來，倉庫還是「未識別」。
- **不要手改**：碼自帶校驗，改一個字元（加個空格也算）就失效。
- **不要括引號**：寫成 `"SCM3 …"` 會被當成引用文字忽略掉。

其餘都寬鬆：順序隨意、中間空幾行隨意、夾標題和說明文字隨意、包在 Markdown 程式碼區塊裡隨意、同一行用空格連著寫兩段也認。整個檔案別超過 64 KB。

## 玩家那邊看到什麼

類型 / 對象標籤和「需要重新啟動」都來自那段資訊碼，掃描時自動判定，你不用手填。包裝好遊戲不會立刻載入，所以面板會像 Steam 一樣提示「需要重新啟動」，重新啟動後才生效。

## 幾個坑

- **改倉庫名、或換帳號**：`作者/倉庫` 變了，舊資訊碼立刻作廢，重新掃一次再提交。
- **只發零散 dll / pck、不發 zip**：倉庫會列出來，但永遠是「未識別」，沒有安裝按鈕。
- **貼了別的倉庫的碼**：同樣算「未識別」——碼是和倉庫綁定的。
- **更新外觀**：發新 Release 就行。只有**替換對象變了**，或者**加了腳本 / DLL（重新啟動要求變了）**才需要重新掃描、更新 `sc.info`；只換圖片不用。

支援的替換對象：角色、卡片、怪物、先古、商人、夥伴、事件。
