# GitHub에 스킨 모드 게시하기(작성자 가이드)

[简体中文](投稿GitHub皮肤Mod说明.md) · [English](publish-github-skin-mod.md)

「Skin Changer」를 설치한 플레이어는 게임 내 **☼스킨 창작마당 → 출처: GitHub**에서 당신의 저장소를 보고 클릭 한 번으로 설치할 수 있습니다.
해야 할 일은 세 가지뿐입니다: 태그 하나 추가, zip 하나 게시, 코드 하나 붙여넣기.

(자신의 패키지를 스캔하려면 먼저 Steam 창작마당에서 「Skin Changer」를 검색해 설치하세요.)

## 1. 태그 추가하기

저장소 페이지 오른쪽 About 옆의 톱니바퀴 → Topics에:

```
sts2-sc-mod
```

태그가 없거나 철자가 틀리면 게임이 저장소를 찾지 못합니다. fork한 저장소도 표시되지 않습니다.

## 2. Release에 zip 첨부하여 게시하기

- zip의 내용은 게임이 불러올 수 있는 스킨 패키지입니다(`<id>.json` + `.pck` / `.dll`. 카드 그림만 있는 소재 팩도 가능).
- 파일은 zip의 **루트**에 두거나 폴더 안에 넣으세요(몇 겹이든 상관없습니다. 패키지에 모드가 여러 개 들어 있을 때만 저장소와 같은 이름의 폴더를 우선 선택합니다).
- 읽는 것은 `.zip`뿐입니다: `.rar`, `.7z`, `.tar.gz`는 첨부가 없는 것으로 취급되어 저장소가 「인식되지 않음」에 머뭅니다.
- **최신** Release에 첨부하고 **pre-release는 체크하지 마세요**(체크하면 패널이 읽지 못합니다). 첨부 파일 하나는 128 MB 이하여야 합니다.
- zip 하나가 가장 편합니다. 여러 개 올리면 저장소와 같은 이름을 우선하고, 없으면 가장 큰 것을 선택합니다.
- zip은 **Release를 먼저 게시한 뒤에 추가해도 됩니다**: 「스캔」할 때 실시간 Release를 다시 읽으므로 tag 변경이나 재제출이 필요 없습니다.

## 3. 코드를 sc.info로 저장하기

1. 게임 내 → ☼스킨 창작마당 → 출처를 **GitHub**로 전환 → 필터를 **인식되지 않음**으로 → 저장소를 찾으세요.
2. **스캔**을 클릭(이때만 zip이 다운로드되며, 끝나면 바로 삭제됩니다). 창에 1개 이상의 **코드**가 표시되고 각각에 복사 버튼이 있습니다.
3. **저장소 루트**에 `sc.info`라는 이름의 파일을 만들고 코드를 붙여넣은 뒤 커밋하세요.
4. 게임으로 돌아와 새로 고침을 누르면 저장소가 「인식되지 않음」에서 설치 가능한 스킨으로 바뀝니다(카드 이름은 **저장소 이름**을 사용합니다).

### 여러 코드 붙여넣기

**코드 하나에 한 줄씩, 위에서부터 차례로 붙여넣으세요**. 그게 전부입니다:

```
SCM3 6714 3f2a…(예시. 실제는 한 줄로 된 긴 문자열)1/2 eJw…Cd34
SCM3 6714 3f2a…(예시. 실제는 한 줄로 된 긴 문자열)2/2 eJw…Cd34
```

지켜야 할 규칙은 네 가지뿐입니다:

- **코드를 줄바꿈으로 끊지 마세요**: 하나의 코드는 반드시 같은 줄 안에 있어야 합니다. 편집기가 긴 줄을 접어 보여 주는 것은 괜찮지만, 코드 중간에 Enter를 누르면 망가집니다.
- **하나도 빠뜨리지 마세요**: 창에 표시된 만큼 붙여넣으세요. 하나라도 빠지면 패키지 전체를 읽지 못해 저장소가 「인식되지 않음」에 머뭅니다.
- **수동으로 수정하지 마세요**: 코드에는 체크섬이 있어 한 글자만 바꿔도(공백 추가도) 무효가 됩니다.
- **따옴표로 감싸지 마세요**: `"SCM3 …"`는 인용 텍스트로 취급되어 무시됩니다.

나머지는 자유입니다: 순서 무관, 빈 줄 무관, 제목과 설명을 섞어도 OK, Markdown 코드 블록으로 감싸도 OK, 한 줄에 공백으로 두 개를 나열해도 인식됩니다. 파일 전체는 64 KB 이하로.

## 플레이어에게 보이는 것

유형 / 대상 라벨과 「재시작 필요」 표시는 코드에서 옵니다. 스캔 시 자동으로 판정되므로 직접 입력할 필요가 없습니다. 새로 설치된 패키지는 실행 중인 게임에 바로 로드되지 않으므로, Steam과 마찬가지로 패널이 재시작을 안내하고 재시작 후 적용됩니다.

## 자주 하는 실수

- **저장소 이름 변경이나 계정 전환**: `소유자/저장소` 쌍이 바뀌면 이전 코드는 즉시 무효입니다. 다시 스캔하여 새로 커밋하세요.
- **zip 없이 dll / pck만 게시**: 저장소는 목록에 올라오지만 「인식되지 않음」이며 설치 버튼이 없습니다.
- **다른 저장소의 코드 붙여넣기**: 마찬가지로 「인식되지 않음」— 코드는 해당 저장소에 묶여 있습니다.
- **스킨 업데이트**: 새 Release를 게시하면 됩니다. **교체 대상이 바뀌었을 때**, 또는 **스크립트 / DLL을 추가했을 때(재시작 요구가 바뀜)**만 다시 스캔하여 `sc.info`를 업데이트하세요. 이미지만 교체할 때는 필요 없습니다.

지원하는 교체 대상: 캐릭터, 카드, 몬스터, 고대인, 상인, 동료, 이벤트.
