# 游戏内工坊清单核验规则

- 清单新增或更新物品时，先检查实际包的启动代码、前置、版本和完整资源接管，再填写重启标签；只展示“需要重启 / 可免重启”，不提供“不兼容 / 待确认”标签。
- 不能仅凭没有 DLL、已被收录或启动时已加载就宣称免重启。
- 本地包缺失时，先告诉用户具体 Mod，让用户重新订阅并完成下载，再继续核验；不得擅自赋予任何分类，也不以“保守”或“兜底”为由标成需要重启。清单工具必须停下并保持已有文件不变。
- 使用 `WorkshopCatalogExport --refresh-restart-hints` 检查正式版与测试版基线，实际订阅时仍复核文件，具体失败原因单独显示。
