# GitHub でスキンを公開しよう（作者向けガイド）

[简体中文](投稿GitHub皮肤Mod说明.md) · [English](publish-github-skin-mod.md)

「Skin Changer」を導入したプレイヤーは、ゲーム内の **☼スキンワークショップ → 取得元：GitHub** にあなたのリポジトリを見つけ、ワンクリックでインストールできます。
やることは 3 つだけ：タグを 1 つ追加、zip を 1 つ公開、コードを 1 つ貼り付け。

（自分のパッケージをスキャンするには、まず Steam ワークショップで「Skin Changer」を検索して導入してください。）

## 1. タグを追加する

リポジトリページの About 横のギアアイコン → Topics に：

```
sts2-sc-mod
```

タグが未追加やスペルミスだと、ゲームがあなたのリポジトリを見つけられません。fork したリポジトリも表示されません。

## 2. Release に zip を添付して公開する

- zip の中身は、ゲームが読み込めるスキンパッケージ（`<id>.json` + `.pck` / `.dll`。カード絵だけの素材パックでも可）。
- ファイルは zip の**ルート**に置くか、フォルダに入れてください（入れ子は何層でも OK。パッケージに複数の Mod が入っているときだけ、リポジトリと同名のフォルダが優先されます）。
- 読み込まれるのは `.zip` だけ：`.rar`・`.7z`・`.tar.gz` は添付なし扱いになり、リポジトリは「未認識」のままです。
- **最新**の Release に添付し、**pre-release はチェックしない**でください（パネルから読めなくなります）。1 つの添付は 128 MB 以内。
- zip は 1 つが一番楽です。複数ある場合は、リポジトリと同名のものが優先され、なければ最大のものが選ばれます。
- zip は **Release 公開後に追加しても構いません**：「スキャン」時に最新の Release を読み直すので、tag の変更や再提出は不要です。

## 3. コードを sc.info として保存する

1. ゲーム内 → ☼スキンワークショップ → 取得元を **GitHub** に切り替え → フィルタを **未認識** に → あなたのリポジトリを探す。
2. **スキャン** をクリック（ここでだけ zip がダウンロードされ、終わるとすぐ削除されます）。ウィンドウに 1 つ以上の**コード**が表示され、それぞれにコピー ボタンがあります。
3. **リポジトリのルート**に `sc.info` という名前のファイルを作成し、コードを貼り付けてコミット。
4. ゲームに戻って「更新」を押すと、リポジトリが「未認識」からインストール可能なスキンに変わります（カードの名前は**リポジトリ名**になります）。

### 複数のコードの貼り方

**1 つのコードを 1 行に、上から順に貼る**。それだけです：

```
SCM3 6714 3f2a…（見本。実際は 1 行の長い文字列）1/2 eJw…Cd34
SCM3 6714 3f2a…（見本。実際は 1 行の長い文字列）2/2 eJw…Cd34
```

絶対守るべきルールは 4 つだけ：

- **コードを改行で分割しない**：1 つのコードは必ず同じ行に収める。エディタの折り返し表示は問題ありませんが、コードの途中で Enter を押すと壊れます。
- **1 つも漏らさない**：ウィンドウに表示された数だけ貼る。1 つでも欠けるとパッケージ全体が読めず、リポジトリは「未認識」のままです。
- **手を加えない**：コードにはチェックサムがあり、1 文字でも変える（スペースを足すだけでも）と無効になります。
- **引用符で囲まない**：`"SCM3 …"` は引用テキストとみなされて無視されます。

それ以外は自由です：順序は不問、空行は不問、見出しや説明文を挟んでも OK、Markdown のコードフェンスで囲んでも OK、1 行にスペース区切りで 2 つ並べても OK。ファイル全体は 64 KB 以内に。

## プレイヤーに見えるもの

タイプ / 対象ラベルと「再起動が必要」の表示はコードから来ます。スキャン時に自動判定されるので、手入力は不要です。インストール直後のパッケージは実行中のゲームには読み込まれないため、Steam と同様にパネルが再起動を案内し、再起動後に有効になります。

## よくあるミス

- **リポジトリ名の変更やアカウントの切り替え**：`作者/リポジトリ` の組が変わると古いコードは無効です。再スキャンして新しいものをコミットしてください。
- **zip なしで dll / pck だけを公開**：リポジトリは一覧に載りますが「未認識」のままで、インストール ボタンが出ません。
- **別のリポジトリのコードを貼る**：これも「未認識」——コードはそのリポジトリに紐付いています。
- **スキンの更新**：新しい Release を公開するだけで OK。**置き換え対象が変わった**とき、または**スクリプト / DLL を追加した（再起動要件が変わる）とき**だけ再スキャンして `sc.info` を更新してください。画像の差し替えだけなら不要です。

対応する置き換え対象：キャラクター、カード、モンスター、エンシェント、商人、仲間、イベント。
