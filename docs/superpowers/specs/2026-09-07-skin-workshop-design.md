# 游戏内皮肤创意工坊

已由用户在会话中确认。不是全站搜索器，也不恢复旧的联机临时下载功能。

- 随 Mod 分发人工维护的 Workshop ID 与类型/目标标签清单，首批从本机已订阅且目录实际识别的皮肤生成；本地 Mod 不收录。
- 每次启动首次打开时按内置清单刷新名称/封面地址（分语言缓存，不扫描工坊）；翻页、筛选、重开共享请求与结果，包括离线回退。封面首次显示时按需读取，启动内复用已解码的小缩略图，关闭页面不取消共用请求或释放缓存。没有资料时名称显示“…”、图片使用主题强调色圆角占位。
- 所有实际换肤下拉框末尾添加强调色“☼创意工坊”命令，按当前对象/分类筛选。该命令不是皮肤，不能保存、参与随机、合并或管理器前后切换。
- 面板沿用凉玉主题，包含筛选、封面、名称、订阅/下载状态和关闭；长列表滚动，操作不穿透。
- 类型为“全部”时不显示次级筛选；怪物和事件先按地区，再按具体对象筛选；其它类型按对象/卡牌分类。所有筛选列表每页最多十个具体对象，名称取游戏本地化；生物不含奥斯提。
- 工坊标题同入口为“☼创意工坊”；物品两列、每页四行排列，每项外包主题面板，增高面板以容纳标准字号下四行，大字号仍保留滚动兜底。长标题悬停该项时平移，名称自身悬停变为主题强调色，鼠标移开立即恢复普通文字色，键盘焦点保留原生焦点框而不锁住文字颜色；点击名称或封面在 Steam 打开同一物品页。封面使用主题圆角。每个标签是可点击筛选的按钮。关闭在左侧，两个翻页按钮集中在右侧。不显示“可使用”；下载完成且需要重启时由右侧“需要重启”按钮执行游戏正常退出/重启，不重复显示状态，仍保留下载进度和错误。
- 允许玩家主动取消订阅，调用 Steam API 并确认结果；显示“已取消订阅 / 关闭游戏后自动删除”。保留当前运行已加载资源，不删除文件或强制清空皮肤选择，由 Steam 退出后移除。进行中的订阅/退订操作互斥，失败保留错误供重试。
- 玩家主动订阅的内容由 Steam 永久管理，不在离房/结束对局时删除。后台下载，百分比来自 Steam；未知总量显示等待而非伪造进度。
- 下载完检查实际安装目录和完整接管能力。只有无新增代码/依赖初始化且资源能完整解析的提供者才热注册；其余保留订阅并明确提示重启，不发布半个皮肤。
- 已加载且满足版本的前置不阻止检查；可通过只读 IL 检查证明无需执行的启动 DLL 也可继续完整资源检查，不执行原 Mod 的未知逻辑。版本不兼容单独报错。
- 内置清单记录已审计版本的重启标注，订阅前即显示可筛选标签“需要重启”或“待确认”；不能把未审计项标为免重启。实际下载检查优先，免重启注册成功才标“可免重启”，版本/包不兼容标“不兼容”；启动时已加载不代表免重启注册通过。标签变化会更新当前筛选的成员和页数。
- 重启筛选的默认文案为“全部”。清单收录表示已识别的皮肤来源，不是完成了逐包免重启验证：当前导出仅检测启动代码，其余项还需检查包内资源/脚本/前置和完整接管。该检查可对已有本地文件提前进行，并不必须等玩家订阅。界面列出的“不兼容”筛选项本身不表示已有物品命中；只有实际版本或包检查拒绝才赋予该标签。
- 本面板发起的订阅仅用标签、下载状态和操作按钮反馈，不弹专用或游戏原生的重启提示，晚到的通知同样抑制；其它来源的通知不受影响。浏览器仍避让其它原生弹窗。
- 标题旁“投稿模组”打开固定的模组投稿讨论区；主题预设面板“复制预设码”右边“投稿预设”打开固定的主题投稿讨论区。优先 Steam 覆盖层，否则使用 Steam 协议；只打开页面，不代替玩家发表内容。
- 新皮肤注册只增加选择，不自动覆盖玩家现有设置。异常不清空旧目录/设置。
- 兼容正式版和测试版，15 种语言，不主动启动游戏。直接 master、内测版本递增并提交；本轮未授权工坊发布。
