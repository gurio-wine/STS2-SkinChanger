# Опубликуйте свой облик на GitHub (руководство для авторов)

[简体中文](投稿GitHub皮肤Mod说明.md) · [English](publish-github-skin-mod.md)

Игроки с установленным «Skin Changer» увидят ваш репозиторий в игре: **☼Мастерская скинов → Источник: GitHub** — и установят его в один клик.
Сделать нужно всего три вещи: добавить один топик, опубликовать один zip, вставить один код.

(Чтобы отсканировать собственный пакет, сначала установите Skin Changer — найдите его в Мастерской Steam.)

## 1. Добавьте топик

На странице репозитория: шестерёнка рядом с About → Topics:

```
sts2-sc-mod
```

Без топика или с опечаткой игра не найдёт ваш репозиторий; fork-репозитории тоже не показываются.

## 2. Опубликуйте Release с zip

- В zip лежит пакет облика, который загружает игра (`<id>.json` + `.pck` / `.dll`; подходит и пак только с карточными артами).
- Файлы кладите либо в **корень** zip, либо в папки (любая глубина; папка с именем репозитория предпочтительна, только если в zip несколько модов).
- Читаются только `.zip`: `.rar`, `.7z` и `.tar.gz` считаются отсутствием вложения — репозиторий останется «Не распознано».
- Прикрепите к **последнему** Release и **не** помечайте его как pre-release (панель такие не читает). Одно вложение — не больше 128 МБ.
- Проще всего один zip. Если несколько, панель предпочитает названный в честь репозитория, иначе — самый большой.
- Zip можно **добавить уже после публикации Release**: при «Сканировать» перечитывается актуальный Release, новый тег или повторная отправка не нужны.

## 3. Сохраните код как sc.info

1. В игре → ☼Мастерская скинов → Источник **GitHub** → фильтр **Не распознано** → найдите свой репозиторий.
2. Нажмите **Сканировать** (только в этот момент ваш zip скачивается и сразу удаляется). В окне появится один или несколько **кодов**, у каждого кнопка копирования.
3. В **корне репозитория** создайте файл `sc.info`, вставьте коды и сделайте коммит.
4. Вернитесь в игру и нажмите «Обновить»: репозиторий превратится из «Не распознано» в устанавливаемый облик (имя карточки — **имя репозитория**).

### Как вставить несколько кодов

**Один код — одна строка, сверху вниз.** Вот и всё:

```
SCM3 6714 3f2a… (иллюстрация; реальный код — одна длинная строка) 1/2 eJw…Cd34
SCM3 6714 3f2a… (иллюстрация; реальный код — одна длинная строка) 2/2 eJw…Cd34
```

Жёстких правил всего четыре:

- **Не разрывайте код по строкам.** Код должен целиком оставаться в одной строке. Перенос длинной строки редактором не страшен; нажатие Enter внутри кода — фатально.
- **Вставьте все коды.** Столько, сколько показало окно. Пропустите один — весь пакет не прочитается, репозиторий останется «Не распознано».
- **Не редактируйте код.** В каждом есть контрольная сумма; изменение одного символа (даже добавление пробела) ломает его.
- **Не берите код в кавычки.** `"SCM3 …"` считается цитатой и игнорируется.

Остальное свободно: порядок не важен, пустые строки не важны, заголовки и текст вокруг кодов допустимы, ограждение Markdown-кода допустимо, два кода через пробел в одной строке тоже читаются. Держите файл меньше 64 КБ.

## Что видят игроки

Метки типа/цели и подсказка «требуется перезапуск» берутся из кода — они определяются при сканировании, вручную их заполнять не нужно. Свежеустановленный пакет не загружается работающей игрой, поэтому панель, как и Steam, предлагает перезапуск; он вступает в силу после перезапуска.

## Частые ошибки

- **Переименование репозитория или смена аккаунта**: пара `владелец/репозиторий` меняется, старые коды перестают работать — отсканируйте заново и закоммитьте новые.
- **Только россыпь dll / pck без zip**: репозиторий виден в списке, но навсегда «Не распознано», без кнопки установки.
- **Код от другого репозитория**: тоже «Не распознано» — код привязан к своему репозиторию.
- **Обновление облика**: просто опубликуйте новый Release. Заново сканировать и обновлять `sc.info` нужно, только если **изменились заменяемые цели** или вы **добавили скрипт / DLL (изменилось требование перезапуска)**; замена картинок этого не требует.

Поддерживаемые цели замены: персонажи, карты, монстры, Древние, торговцы, спутники, события.
